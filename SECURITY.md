# Security Policy

[← Project overview](README.md) · [Support](SUPPORT.md)

## Scope

This public repository currently distributes **documentation**, not executable installers or the private ReplayMovies/FMVFix source trees. No statement on this page constitutes a guarantee that every Windows build, third-party injection stack or older modded executable is secure.

## Reporting a sensitive issue

Do **not** put exploit details, secrets, credentials, personal data, private source, proprietary movie assets or weaponizable proof-of-concept binaries in public Issues or pull requests.

If **GitHub private vulnerability reporting** is enabled, use that feature. Otherwise request a private communication channel with the repository maintainer before sharing sensitive materials. Do not assume a public issue is private merely because it is labeled security-related.

## What belongs in an ordinary documentation report

Corrections to public descriptions, links, test scope, or non-sensitive compatibility notes can use the normal documentation workflow described in [Contributing](CONTRIBUTING.md).

## Release integrity

Installable `.asi` modules are intended to be distributed through official **Nexus Mods** pages once available. Verify the actual publisher and package integrity before installation; this GitHub documentation archive does not provide plugin binaries or independent security endorsements for third-party files.
