# Security Policy

This repository primarily publishes documentation; installable plugins will be distributed separately on Nexus Mods.

Do not publish security-sensitive exploit details, secrets, credentials, or private project source code in public Issues. If GitHub private vulnerability reporting is enabled for the repository, prefer that mechanism. Otherwise, contact the maintainer via an appropriate private channel before disclosing sensitive details.

No blanket compatibility or security-support commitment is implied for unverified executable variants.
