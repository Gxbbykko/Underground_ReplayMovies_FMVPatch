# Contributing

This repository currently focuses on the accuracy of historical engineering documentation.

- Open a documentation issue or pull request with the relevant chapter, exact claim, and supporting evidence.
- Distinguish runtime-confirmed behavior, static analysis, inference, failed experiments, and superseded assumptions.
- Do not upload proprietary game assets, original Xbox/PC movie files, upscaled MP4s, plugin binaries, or privately withheld source code.
- Keep submitted changes scoped to their relevant engineering chapter. The `main` branch serves as a navigation/publication hub.
- Do not report a successful game runtime test unless you performed it and can provide reproducible evidence.

Issue templates and automated checks will be enabled only after review.
