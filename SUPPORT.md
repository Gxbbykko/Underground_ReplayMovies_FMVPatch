# Support and questions

[← Project overview](README.md) · [Contributing](CONTRIBUTING.md) · [Security](SECURITY.md)

## Where to ask

| Topic | Channel |
| :--- | :--- |
| Typo, broken link, missing citation, document contradiction | Relevant GitHub documentation branch / issue or documentation-focused pull request. |
| Technical question about a completed engineering finding | Reference the named branch and exact `docs/` page; include the specific observed behavior. |
| Installation, user-facing release support and plugin downloads | **Nexus Mods**, after the relevant official pages are published. |
| Vulnerability or private disclosure | Follow the [Security Policy](SECURITY.md), not a public comment with sensitive details. |

## Information useful for a technical report

Please include the **exact English PC executable version**, 32-bit environment, affected feature (`ReplayMovies`, `FMVFix` or `FMVPatch`), selected movie ID (if relevant), and what you expected versus what occurred. For MP4 picture issues, state `Xbox`, `1080p` or `4K` mode; remember that a first-frame MAD fallback under unexpected selection order is **already documented**.

Do **not** attach copyrighted game videos, raw capture data, personal profiles, unredacted debugger logs or private project source.

## Support boundary

The investigated executable is **Need for Speed: Underground (2003), English PC v1.4 x86**. Other localizations, game binaries, third-party wrappers and injected mods have not been universally validated. GitHub's documentation-only archive is **not** an installable release or a guarantee of support for arbitrary setups.

There are no invented download links here. The project will add real Nexus Mods URLs only once listings are public.
