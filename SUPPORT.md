# Support

**GitHub:** Documentation inaccuracies, evidence corrections, repository navigation, and reproducible source-related questions.

**Nexus Mods (after publication):** Ready-to-install plugin downloads, installation guidance, release-specific compatibility notes, and user-facing mod support. Nexus Mods download links will be inserted only when the actual pages exist.

The supported reverse-engineering baseline is Need for Speed: Underground (2003), English PC v1.4 x86. Do not assume other executables are compatible without separate validation.

Please do not upload proprietary movie assets, compiled plugins, or privately held project source code in GitHub Issues.
