# ReplayMovies

**Status:** Completed engineering milestone; maintenance/documentation chapter.

ReplayMovies adds a native-style **REPLAY MOVIES** option to the Need for Speed: Underground (2003) PC Main Menu. The established design uses Underground's own frontend objects, selection/navigation infrastructure, and native FMV activation/teardown lifecycle. The documented career catalog contains 17 movies; the automatic startup intro sequence is not part of that career replay catalog.
